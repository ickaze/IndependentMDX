# IndependentMDX 0.24

## 0.24の変更

0.23に音色番号重複時のスキップ処理を加えた版です。同じ音色番号は最初の定義を採用し、後続の同番号の定義を読み飛ばします。別番号の音色は引き続き読み込みます。66組の回帰テストが成功しました。調査は終了し、これ以上の専用対応は追加していません。

## 0.23の変更

MH・MP・MAのスイッチ判定をビット単位へ変更しました。bit7が1ならON/OFF形式とし、bit0が0ならOFF、1ならONです。未使用のbit1～6は判定に使いません。0xFEはOFF、0xFFはONとして読み進めます。

MP/MA設定形式はbit0～1を波形、bit2を256倍モードとして使用し、残りの未使用ビットを無視します。MHのPMS/AMSは0x73でマスクします。リピート読み飛ばし時の引数長判定もbit7に統一しました。

周期、音色番号、q値、ファイル内参照などの数値項目は従来の範囲検査を維持します。未対応命令を他の命令に置き換えたり、破損した参照を推測したりする処理は追加していません。

3種類のLFOスイッチの0x80～0xFF全値、未使用波形ビット、PMS/AMSを含む65組の回帰テストを確認しました。報告対象データではスイッチのエラーを通過しますが、次の未対応命令0xE3（channel B、offset 0x378）で停止します。完全再生は未達です。Windows実機での実聴は未確認です。

## 0.22の変更

MDXの配置差を、識別文字列に依存しない共通の構造検査で扱うよう整理しました。9／16トラックのオフセット表について、音色とトラックのうち最も手前の境界から表の長さを検証します。音色先行、トラックの格納順の違い、開始位置の共有を扱います。

固有パターンに基づく開始位置の復元、専用のテンポ・待ち時間、音色選択の例外を削除しました。境界外の参照、不完全な表、構造を確定できない入力は値・位置・期待範囲を伴うエラーにします。壊れた命令の推測実行や任意コードの実行は行いません。

専用処理とそれに関する解析記録・記述・テストを配布物から除去しました。従来の専用処理で再生できたファイルは、今回の共通処理で再生できるとは限りません。法的な適否を保証する変更ではありません。

配置の異なる合成データで音声・開始時刻の一致を確認し、既存の音源・LFO・MIDI等を含む64組のテストが成功しました。Windows向けGUI/CLIを再ビルドしました。Windows実画面・実聴は未確認です。

## 0.21の変更

矩形波のソフトウェア音程LFO（MP）に余分な256倍が掛かっていた処理を修正しました。固定小数点で格納された変移値とWAVE+4による倍率の適用後に、矩形波だけをさらに256倍していたためです。

振幅1は中心から±1/64半音、振幅−24は極性を反転した±24/64半音として扱います。全振れ幅（上下の差）はそれぞれ2/64半音と48/64半音です。格納周期Pごとの符号反転は維持します。

修正範囲はMPの矩形波（WAVE1/5）です。他のMP波形、MA、OPMLFOと、0.20で戻したキーオフ後の停止処理は維持しています。MDXの固定小数点表現（WAVE1）と256倍モード（WAVE5）の両方で、振幅1/−24と周期をKC/KFレジスタから検査しました。

64組の回帰テストが成功し、Windows向けGUI/CLIを再ビルドしました。今回のMMLをコンパイルした実ファイルは未提供のため、合成MDXによる検証です。Windowsでの実聴は未確認です。

## 0.20の変更

0.16で追加したソフトウェア音程LFO（MP）・音量LFO（MA）のリリース中の継続処理を撤回しました。0.15と同様に、キーオン中だけ位相とMD遅延カウントを進め、キーオフ後・休符中・曲末では停止します。キーオフ時に音程や音量を初期値へ戻す処理は追加せず、その時点の変調値を保持します。

OPMLFO、MP/MAのON/OFF命令、MDとOPMLFOの分離は変更していません。0.17で修正したポルタメントは独立した処理として、クオンタイズによるキーオフ後も音符末尾まで継続します。0.19のUI・負荷軽減も維持しています。

キーオン中の変調、キーオフ後・休符・曲末での停止、既存のポルタメント等を含む63組の回帰テストが成功しました。Windows向けGUI/CLIを再ビルドしています。Windows上での実際の試聴は未確認です。

- スプリッター操作時の点滅・操作不能対策として、0.14のWS_EX_COMPOSITED切り替えを撤去しました。ドラッグ中だけ専用のメモリ画像へ各部品を描画し、完成した画面を一括表示します。更新は約33msごとにまとめ、位置が変わらないマウスイベントでは再配置しません。解放／操作中断時は通常表示へ戻します。Windows実画面での検証は未実施です。

- 実測出力タイミングがMIDI／音色画面の試奏ではON固定だった不具合を修正し、演奏中もスイッチを反映します。MDX再生側の切り替えは既存処理でも有効でした。**Independent OPM DLLのALG5・ALG7**が音声への適用対象です。X68Sound／C86CTLを選ぶとスイッチを無効表示にします。詳細は[出力タイミングと波形表示](docs/TIMING_AND_WAVEFORMS_0.15.md)を参照してください。

## 0.14の変更

- スプリッターを押している間だけ画面全体をダブルバッファ合成します。ドラッグ中も現在の配置を描き直し、ボタンを離した時・操作が中断された時は通常描画へ戻します。
- 表示切り替えの右に **キャリア音程**（初期OFF）を追加。FMの各キャリアのML・DT2から求めた音程を鍵盤／ピアノロールに表示します。ALG0～3は1音、ALG4は2音、ALG5／6は3音、ALG7は4音。同じ音程のキャリアは同じ鍵盤に重なります。1オクターブを**超える**ずれは12半音で折り返します（ML=0の−12半音、ML=2の＋12半音はそのまま）。半音未満は最寄りの鍵盤へ丸め、表示範囲外の音は省きます。PCMの表示と実際の音は変更しません。
- キー設定の上に **再生速度 0～200%**（初期100%）を追加。MDXはFM/PCMの命令・発音タイミングを変え、音高やOPMLFO・エンベロープのチップ内速度は維持します。ソフトLFOはMDXのクロックに従います。0%は曲の進行を停止し、試奏は可能です。再生位置・シークは100%時の曲内時刻を基準にします。単独PDXの試聴ではサンプル読み出し速度を変えるため音高も変わります。WAV保存は従来の100%です。
- 音色表示の音色一覧の上に試奏鍵盤を追加。クリック／押したまま横移動、または **AWSEDFTGYHJK** でCからBまでの12音を演奏できます。**PageUp／PageDown** でオクターブを変更（初期o4、o1～o7）。文字は現在のオクターブの鍵盤だけに表示します。Mono／Poly選択に連動し、PolyはFM最大8音。音色画面内のテキストや一覧にフォーカスがあっても演奏でき、Ctrl+A／Ctrl+Cは編集操作を優先します。別ウィンドウへの移動・画面を閉じる操作・オクターブ／Mono／Poly変更で押鍵を解放します。
- 音色テキストとMML保存のOP2／OP3を訂正し、接続図と同じ **OP1, OP2, OP3, OP4（M1,C1,M2,C2）** 順にしました。レジスタ表示は引き続きアドレス順です。
- キャリア音程モード・再生速度は従来の2秒後保存の対象です。

## 0.12の変更

- MDはソフトウェア音程／音量LFO（MP/MA）にのみ適用します。OPMLFOのPMS/AMSをMD実行・再キーオン・遅延経過時に消去／復元する処理を廃止しました。EA80=MHOF／EA81=MHONは維持します。ソフトLFOの三角波・タイの扱いは0.11から変更していません。

- 数値入力欄とプルダウンの高さをそろえ、行間・外周余白を縮小しました。ファイル一覧は残りの縦幅に合わせて広がります。小さい画面や高DPIで必要な場合のスクロールは維持します。

## 0.9の変更（履歴）

- ハードウェアLFOを `EA 80 = MHOF / EA 81 = MHON` に訂正しました。旧版は逆に判定しており、OFFのつもりの80でPMS/AMSを復元していました。0.8の説明・テストもその誤った前提でした。ソフトウェアLFOのEC/EBスイッチは変更していません。
- 再生スライダーの空白クリックをページ単位の増減から、クリックした位置への移動に変更しました。そのままドラッグもできます。つまみのドラッグ・キーボード操作は継続して使えます。
- X68Sound選択時は波形用の追加FM演算とチャンネル波形描画を停止します。鍵盤の音程表示は残します。DLLのGetPcmを1サンプルずつ呼ぶ方式からレジスタ変更間のまとめ生成へ変更し、プロセス間の受け渡しも1024内部サンプル単位にしました。FM側の受け渡し遅延は約16.4msです。

- ノートオフ、サステイン、音量、ベンドは元の入力チャンネルに対応する発音へ振り分けます。割り当て先の鍵盤にも発音を表示し、マスク中でもMIDI発音キーは点灯します。PCMは音程に対応するPDXサンプルを各チャンネルの保持バンク／形式で再生する従来の方式です。
- 一時停止の開始時に音色・レジスタ・PCM設定を退避し、解除時はMIDI発音を消音して元の状態へ戻してから曲を再開します。停止中の試奏にはこの一時復元は適用しません。通常の曲再生中は従来どおりMIDI入力チャンネルと再生チャンネルを対応させます。

Windows実画面・MIDI機器・X68Sound DLL・C86CTL実機での確認は未実施です。音切れの解消は実機での再確認が必要です。

### C86CTLの準備・制限

公式配布の64bit `c86ctl.dll` をEXEと同じフォルダーへ配置してください（本ZIPには含めていません）。OPM/YM2151として識別された最初のデバイスを使用します。GIMICのPLL APIが使える場合は4MHzへ設定し、それ以外はハードウェア側で4MHzに設定してください。OPNA等へは送信しません。公式配布元: https://www.c86box.com/software.html

## ファイル一覧と鍵盤

一覧のアドレス欄にフォルダーを入力してEnterで移動します。「戻る」「上へ」、フォルダーのダブルクリック／Enterでも移動できます。初期列は名前・作成日時・更新日時・種類・サイズです。列見出しをドラッグして順序を変更し、境界をドラッグして幅を変更できます。見出しの右クリックで表示列を追加／削除します。アクセス日時・拡張子・属性・フォルダーも選べます。

右側はFM8chとPCM8chを各96段階で表示します。FMはKCの8オクターブ全域に対応し、4MHzでの基音に合わせたおおよそのD♯0〜D8の鍵盤配置です（KF、デチューン、倍音／オペレーター倍率による周波数範囲は別です）。PCMの鍵盤は音高測定ではなく、バンク内サンプル番号0〜95をFMと同じo0D♯〜o8Dの位置へ対応付けます。鍵盤行のクリックでそのチャンネルをマスクします。

保存対象は無限ループ、次曲自動再生、キー、キー変更対象、ブックマーク、表示言語、各音量、周回数、PDX番号／形式、タイミング設定、各マスク、フォルダー、フィルター、列の種類／順序／幅、ソート対象／向き、ウィンドウ位置／サイズです。履歴スタックと現在の再生位置は保存しません。

## 起動と操作

`bin/IndependentMDX.exe` を起動し、MDXまたはPDXを開くか画面へドロップします。PDXはMDXと同じフォルダーから検索し、「PDXを指定」で別のファイルを選べます。番号付きコピーは候補が1つの場合にだけ自動選択します。

再生、一時停止／再開、停止、48kHz・16bitステレオWAV保存に対応します。保存中の停止では、その時点までの音声を有効なWAVとして残します。合成テスト曲 `samples/DEMO.MDX` と `samples/DEMO.PDX` を同梱します。

初回はWindowsのユーザー表示言語が日本語なら日本語、それ以外なら英語です。「表示言語 / Language」からいつでも切り替えられ、選択は実行ファイルの隣の `IndependentMDX.ini` の `Language` に保存します。次回起動は保存した選択を優先します。音声再生を停止せず切り替え可能です。

ボタン・ラベルは実際のUIフォントで文字幅を計測し、余白を加えた幅で行内へ再配置します。言語変更時に必要な表示領域を再計算します。画面が狭い場合はウィンドウ内のスクロールで全操作へアクセスできます。入力欄とコンボボックスは値を保持し、パス欄は横スクロール、ログ欄は縦スクロールで長文を扱います。DPIは起動時のシステムDPIを使用します。

| PDX単体試聴 | 0始まりの番号。マルチバンクはバンク×96＋バンク内番号 |
| F0〜F4 | OKI ADPCM、3.906 / 5.208 / 7.812 / 10.416 / 15.625 kHz |
| F5 / F6 | 符号付き16bitビッグエンディアン / 符号付き8bit、15.625 kHz。明示選択 |
| 時間制限 | GUIは時間制限なし（有限ループ回数は有効）。フェード3秒。終端の余韻は最大0.5秒 |
| 相対音量 | FA減小 / F9増大、FM粗音量は16段階の減衰表、PCMは段階音量へ変換 |
| ソフトLFO | MPON/MPOF・音量LFOのON/OFF、OFF時の変調解除、ON時の位相初期化 |
| キー再発音 | 同一内部サンプルのOFF→ONは1サンプルのOFFを保持。タイは継続 |
| ハードLFO | 0.11bの実装を使用。適用範囲と由来は音源付属資料に記載 |

## 出力タイミング

FMコアは4MHz / 64 = 62,500Hzで動作し、保持波形を出力サンプル区間で積分して48kHzへ変換します。

「YM3012時差モデル」はFMの右だけを28クロック＝7.00µs遅延させます。48kHzでは0.336サンプルです。左とPCMには適用しません。初期OFFです。

「実測出力タイミング」は `set_measured_output_timing` を切り替えます。ALG5 / ALG7のキャリア出力タイミングに作用し、初期ONです。右遅延とは独立して併用できます。両設定は再生中も変更でき、音声生成ブロックから適用します。キュー済み音声分の反映遅延や切り替え時のクリックが生じる場合があります。WAV保存は開始時の音源設定・マスク・音量を固定します。

この出力段は簡易な保持＋区間積分方式です。補間方式の選択機能はありません。実機DACのアナログ特性全体を再現するものではありません。

## コマンドライン

コンソール版は `bin/independent-mdx.exe` です。CLIの診断・ヘルプは英語です。

```bat
bin\independent-mdx.exe samples\DEMO.MDX
bin\independent-mdx.exe song.mdx --pdx bank.pdx --wav output.wav --loops 2
bin\independent-mdx.exe song.mdx --independent-gain 2.0 --fm-mask 125 --dac-delay --measured-output-timing --wav timing.wav
bin\independent-mdx.exe bank.pdx --sample 100 --format 5 --wav sample100.wav
bin\independent-mdx.exe bank.pdx --info
```

CLIでは `--no-measured-output-timing` で実測タイミングをOFFにできます。`--pcm-mask 0..255` はP=1、Q=2、R=4、S=8、T=16、U=32、V=64、W=128のビット和です。PDX単体試聴ではPビットを使用します。

オプション: `--loops 0..1000`（0は無限）、`--seconds 0..3600`（0は時間制限なし）、`--key -24..24`、`--key-mode 0..2`（0: FMのみ、1: PCM速度変更、2: PCMピッチシフト）、`--fade 0..60`、`--gain 0..2`、`--pcm-gain 0..4`、`--independent-gain 0..8`、`--rate 8000..192000`、`--fm-mask 0..255`。マスクはA=1〜H=128のビット和で、125ならB/Hのみ発音します。Spaceで一時停止／再開、Esc/Ctrl+Cで停止。CLIは既存WAVを上書きしません。

## 対応範囲と制限

| 機能 | 対応状態 |
|---|---|
| FM8ch | Independent OPM 0.11bのYM2151、4MHzで合成 |
| PCM1ch / 最大8ch | 独自ソフトウェアミックス。PCM8ドライバーは使用しません |
| 通常のMDXヘッダー | 9ch / 16chのコンパクトなオフセット表に対応 |
| 音色・パン・音量・テンポ・音符・休符 | 対応。FM粗音量はMXDRV段階表。PCMはMXDRV減衰→PCM8段階へ変換。実機アナログバランスは未検証 |
| q / @q、タイ、キーオンディレイ | 対応 |
| 有限リピート、ネスト、最終周の脱出、無限ループ | 対応。有限リピートは独自スタックで管理 |
| 同期送出・同期待ち | 対応。全トラックが待ち状態ならエラー停止 |
| デチューン・ポルタメント | 対応。実機の整数オーバーフロー挙動は再現しません |
| ハードウェアLFO・ノイズ | Independent OPM 0.11bで合成 |
| ソフトウェアLFO | 鋸波・矩形波・三角波・サンプル＆ホールドを独自に近似。位相・振幅・開始動作のMXDRV完全一致は未検証 |
| E7拡張 | 01のフェード（速度は近似）、03のキーオフ制御に対応 |
| E6拡張 | 01相対デチューン、02移調、03相対移調に対応 |
| E7 02などのPCM8直接制御 | 未対応。位置付きエラーで停止 |
| E7他ch制御・音長加算、未定義命令 | 未対応。位置付きエラーで停止 |
| PDX | 通常96スロット、32bit長、連続した96項目単位のマルチバンク表に対応 |
| P16/P8 | F5/F6として明示的に選択したデータを上記規則で再生。拡張ドライバーの全モード対応ではありません |
| 圧縮PDX / LZX / 特殊なヘッダー | 未対応。圧縮ライブラリを組み込まず、読み込みエラーにします |
| レジスター直接書き込み | 対応。ただし通常命令が後で同じレジスターを更新する場合の厳密な優先関係は未検証 |
| リサンプリング・実機アナログ特性 | 独自の簡易方式。実機のフィルター、ノイズ、アナログ歪みはモデル化しません |

Windows上のファイル名はUnicodeで扱い、MDX内部のタイトル・PDX名はCP932として解釈します。PDXの検索時は拡張子を補い、英字の大小も照合します。音楽ファイルをネットワークへ送信する機能はありません。

## ビルド

Visual Studio 2022 Communityの「C++によるデスクトップ開発」とCMakeを導入し、`build_vs2022.bat` を実行します。vcpkgや外部音源DLLは不要です。

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

生成先は `build/Release/IndependentMDX.exe` と `build/Release/independent-mdx.exe`。LinuxではCLIのWAV出力とテストを使用できます。Windowsクロスビルド用の `build_cross.sh` も付属します。

## ライセンスと検証

アプリ独自部分は0BSD。音源は `independent-opm/LICENSE.txt` と `independent-opm/THIRD_PARTY_NOTICES.txt` の条件に従います。音源には各チャンネルの波形を読み出す小さな監視用変更を加えています。差分は `docs/CORE_MONITOR_PATCH.diff` に同梱し、ライセンス文書は取得物から変更していません。今回採用した0.11bの音源パッケージは、付属LICENSE.txtにより0BSDとして提供されています。配布時は `THIRD_PARTY_NOTICES.txt` を実行ファイルと同梱してください。

検証結果と未確認事項は `docs/VALIDATION.md`、構成は `docs/DESIGN.md` に記載しています。
