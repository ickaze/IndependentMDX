# IndependentMDX 0.33.5

LFOとシーケンスの検証結果を反映し、MRL 1.2（曲名・PCM8ch・任意のPDX内蔵）、MRZ圧縮出力、大容量ZIPの低メモリ読み込みに対応しました。

Windows 10/11 x64用のMDX / PDX・YM2151 VGM / VGZ / MRL / MRZプレイヤーです。ZIP/LZH/LHA内の選曲にも対応します。FM音声とチャンネル別波形にはIndependent OPM 0.14のDLLを使用します。音源実装ソースは同梱・静的リンクしていません。

[English](README_EN.md) · [変更履歴](CHANGELOG.md) · [検証結果](docs/VALIDATION.md)

## 0.33.5の変更

- 出力レジスタログから独立に導いたソフトウェアLFOの乱数生成式を実装しました。取得数列の埋め込みではなく、16ビット内部状態の更新と途中の乗算結果から生成します。
- デチューンとLFOを加算した音程が符号付き16ビットで桁あふれした際の処理を修正しました。
- 既存LFO比較76ケース、Signed_Probe 58ケース、Random_Depth_Probe 68ケースの**計202ケースで対象レジスタ状態が一致**しました。比較対象が拒否した16入力はこの件数に含めません。
- [生成式・比較結果・検証範囲](docs/RANDOM_LFO_0.33.5.md)。設定は保持します。既存MRL/MRZへ反映するには元MDXから再出力してください。

## 0.33.4の変更

- ランダムMPの深さを下位8ビットの符号付き値として扱うよう修正。128は−128、255は−1、256は0となります。
- ランダムMAの乗算・負値の丸め・8ビット減衰量抽出を修正しました。深さの計算に周期を掛けていた処理を廃止しました。
- MPは最初の進行クロック、MAは指定周期経過後に乱数を更新し、次の更新まで値を保持します。乱数は曲全体で順に取り出します。
- **乱数生成式は近似のままです。比較対象と同じ乱数列・音声になる修正ではありません。** 確認済みの演算と未確定部分は [検証結果](docs/RANDOM_LFO_0.33.4.md) に記載しています。
- 設定を保持します。既存MRL/MRZへ変更を反映するにはMDXから再出力してください。

## 起動

ZIPを展開し、`bin/IndependentMDX.exe`を起動してください。`independent_opm.dll`を同じフォルダーに置きます。.NETやVC++再頒布ランタイムの追加インストールは不要です。Windows標準DLLを利用します。音色テキストの色分けにはWindows標準のMsftedit.dllを動的に読み込みます。

ファイルを開く、ドラッグ＆ドロップ、下部セレクター、コマンドラインで選択できます。PDXはMDXと同じフォルダーから検索し、手動指定も可能です。PDXや音色が欠けた場合は診断を表示して再生可能な部分を継続します。

```bat
bin\IndependentMDX.exe "C:\Music\song.mdx"
bin\IndependentMDX.exe "C:\Music\song.vgm"
```

起動済みの場合は既存ウインドウで指定ファイルを再生します。最小化は維持します。前回のファイルは次回起動時に読み込みます。初回の表示言語はWindowsのユーザー表示言語が日本語なら日本語、それ以外は英語です。手動切り替えも可能です。

## 音色編集

「音色表示」でウインドウの表示／非表示を切り替え、チャンネルまたは下段の音色番号を選びます。音色番号の選択は現在のチャンネルにも適用されます。`*`は再生中に使用済みの音色です。

ノブは左右ドラッグまたはホイールで操作します。OP1〜OP4の順にAR / DR / SR / RR / SL / OL / KS / ML / DT1 / DT2 / AMEを編集し、CON / FL / OPも変更できます。MMLテキストの直接編集とコピーにも対応します。音色番号の変更、範囲外の値、入力途中の不完全なテキストは適用されず、直前の有効な音色が継続します。

編集は音声生成ブロックごとに適用されます。キュー済み音声の分だけ実際に聴こえるまで遅れます。同じ音色番号を使用している全FMチャンネルと、以後その音色を選ぶ発音に反映します。シーク、出力切り替え、一時停止／再開では編集値を維持し、新たな再生開始ではMDXの元の定義から初期化します。「リセット」は現在表示中の音色だけを戻します。VGMの音色表示はレジスタ参照のみで、MDX音色編集の対象外です。

鍵盤クリックで試奏できます。MMLテキスト入力欄以外ではAWSEDFTGYHUJKがドから13音、PageUp / PageDownがオクターブ変更です。初期オクターブは4、範囲は0〜8。Monophonic / Polyphonic設定に従います。「全音色をMML保存」はMDXファイルの元の定義を出力します。編集結果を残す場合は音色ウインドウのMMLテキストをコピーしてください。

## 再生・表示・MIDI

- 再生、一時停止、停止、位置指定、ループ、次曲自動再生、WAV保存に対応。
- 再生速度0〜200%、キー−24〜+24。キーの対象はFMのみ／PCMを含む／PCMを含みピッチシフトから選択。
- 無限ループは再生中の変更も反映。有限回数を超えてからOFFにするとフェードし、フェード開始後は切り替えません。ループのない曲は終端の無音後に再開します。
- FM・PCM・全体音量は出力別に保存。初期値はIndependent OPM / X68SoundがFM 200%、PCM 100%、全体100%、C86CTLがすべて100%。
- MIDI入力、音色番号によるプログラムチェンジ、Mono / Poly、初期OFFのアフタータッチに対応。停止・一時停止中も試奏できます。
- チャンネル別鍵盤／縦ピアノロール、キャリアのML・DT2に基づく音程表示、波形表示の切り替え。鍵盤クリックで消音。
- Alt+Enterで全画面切り替え。スプリッターで鍵盤側の表示幅を変更。

設定は変更から約2秒後に実行ファイル横の`IndependentMDX.ini`へ保存します。更新時は既存INIを残してください。本パッケージには利用者設定を含めていません。

## ファイルセレクター

初期列は曲名／名前／作成日時／更新日時／種類／サイズ。初期ソートは名前です。見出しクリックでソート、ドラッグで順序・幅変更、見出し右クリックで表示列を変更できます。曲名はファイル一覧の表示後に順次読み込みます。

MDX・PDX・VGM/VGZのフィルターは初期ON。上下キーで選択、Enterまたはダブルクリックで再生・フォルダー移動。上の階層へ戻ると元のフォルダーの選択とスクロール位置を復元します。アドレス入力とブックマークにも対応します。

## 出力と対応範囲

Independent OPM DLL / X68Sound DLL / C86CTL (OPM / YM2151)を選択できます。出力変更時は同じ位置から再開します。C86CTLとX68Soundの外部DLLは同梱していません。X68Soundは32bit版を付属ブリッジ経由で使用します。C86CTLは別途対応するx64 DLLと機器が必要です。FM/PCM遅延設定は次回再生から適用します。

Independent OPMの波形はDLLから取得したチャンネル別サンプルです。外部音源のFM波形はDLLによる推定であり、実機の録音を分離したものではありません。実測出力タイミングは初期ON、YM3012右DAC時差モデルは初期OFFです。

VGM/VGZはYM2151と、本ツールが出力する直接PWM形式に対応します。その他の複数音源やDACストリームは未対応。Independent OPMはヘッダーのクロックを使用し、外部出力は4MHzに限定します。詳細は[VGM対応範囲](docs/VGM_SUPPORT.md)。高密度VGMの周期的な聴感上の不具合について、Windows録音による解消確認は未完了です。

## CLIと一括検証

```bat
bin\independent-mdx.exe song.mdx --pdx bank.pdx --wav output.wav --loops 2
bin\independent-mdx.exe song.vgz --wav output.wav
bin\IndependentMDX.exe --validate-folder "C:\Music"
```

CLIの全オプションは`bin/independent-mdx.exe --help`で確認できます。`--validate-folder`はGUIを開かず配下のMDXを検証し、エラーログと対象MDXを収集します。調査フォルダーが変わるたびにコンソールへ表示します。通常起動の`--collect-error-mdx`でもデータエラーを収集します。PDX未発見はエラーログ・収集の対象外です。

## ビルド・ライセンス

Visual Studio 2022 C++デスクトップ開発環境とCMakeで`build_vs2022.bat`を実行します。Zig 0.13.0を使う場合は`build_cross.sh`を使用します。非Windowsのコア検証は別途ビルドしたIndependent OPM共有ライブラリを`INDEPENDENT_OPM_LIBRARY`に指定します。音源ソースはこの配布物には含みません。

LZH用のLhasa 0.6.0（ISC）は同梱ソースから静的リンクされます。追加の解凍ソフトは不要です。
