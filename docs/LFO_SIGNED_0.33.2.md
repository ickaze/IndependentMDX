# Signed MA triangle correction — 0.33.2

この節は0.33.2時点の検証記録です。MD遅延中の扱いと再発音の条件は追加検証により0.33.3で修正されています。現仕様と検証結果は [0.33.3](LFO_SIGNED_0.33.3.md) を参照してください。

## 原因と変更

MA三角波の負の深さをゼロ始点の負方向変位として扱っていたため、キャリアTLがゼロへクリップし、過大な音量になっていました。負の深さでは開始時を最大減衰とし、減衰量がゼロに近づくよう補正しました。MDは変化開始を遅らせますが、この開始減衰量は維持します。正のMAとMPの式は変更していません。整数の折り返し・オーバーフローの完全な互換性を主張するものではありません。

## 比較ログとの照合

他者のドライバー実装ソースは参照せず、提供されたMDXと比較対象のレジスタログのみを使用しました。入力識別はCRC32 `AAE6F196`。楽曲データや曲名は配布物に含めません。

対象は20.647424秒から始まるEトラック、MA波形2・周期192・生の深さ−93、MD1。0x6C/0x74/0x7Cの3キャリアTLを、開始時刻から43,008 OPMクロック間隔で192回、同時刻の書き込み完了後の状態として比較します。

修正後に再出力したログで576/576状態が一致しました。対象の最初の半周期についての検証であり、曲全体のイベント列・音声波形・他の負の深さまで一致したという意味ではありません。音源DLLは変更していません。

| 20.647424 | 12 | 81 |
| 21.012992 | 0 | 69 |

## 自動検証・制限

- 独自MDXでMA2/6、正負、MD0/1/4、全周期、タイ継続、再発音とOFFの回帰テストを追加。全周期・MD4の期待値は修正式の整合性テストであり、比較対象の新規ログによる確認ではありません。
- Native Release CTestは5/5スイート成功。
- 追加70入力は全てMRZを生成し、ZIP CRCおよびMRLのレコード長を検査しました。
- 既存80入力も再出力し、比較可能76ケースの31一致・45不一致を維持。未一致45ケースはランダム波形です。残り4ケースは比較対象ログがありません。
- Windows x64 GUI/CLIとx86ブリッジをクロスビルド。Windows GUI・実機での聴感確認は未実施。

## 追加の比較が必要な箇所

MA0/1の負の値は現在も減衰量を減らす計算ですが、符号による開始位置・反転・下限処理が正しいかを確定するログが不足しています。推測では変更していません。MPの負値についても波形別の端数処理や境界を再確認します。ランダム波形は引き続き近似です。

`samples/LFO_Signed_Probe` の70個で、MP/MA・全8波形の正負とゼロ、MA2周期192のタイ/再発音/MD4を比較できます。全体を比較対象ツールで1ループ・フェードなしで2回記録し、別フォルダーに保存してください。詳細は同フォルダーのREADME_JA.txtとCASES.csvを参照してください。

既存MRL/MRZは変更されません。修正後の挙動を記録するには元MDXから再出力してください。
