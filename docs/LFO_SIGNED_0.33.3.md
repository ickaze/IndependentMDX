# Signed LFO validation — IndependentMDX 0.33.3

検証日: 2026-10-12

## 実装変更

- MA鋸波・矩形波の深さが負の場合、開始時の減衰量を補正します。鋸波は `max(0, −周期×深さ)`、矩形波は `max(0, −深さ)` を固定小数点の変位へ加算します。三角波の補正も保持します。
- MAはMD0で通常再発音しても位相を継続します。MDが正の場合は再発音でリセットし、タイは位相を継続します。MPの再発音処理は今回変更していません。
- MAのMD待機中は符号によらず通常の音量です。発音時のクロックを含めて数えるため、MD1は待機なし、MD4は3クロック待機です。0.33.2の「待機中も負の三角波の開始減衰量を維持する」という一般化を修正しました。
- ランダム波形の生成式・深さの処理は未修正です。互換性を確認できていない近似のままです。

## 比較結果

独自生成したMDXを別ツールで2回記録したMRLと、修正版から再出力したMRZを比較しました。他者のドライバー実装ソースや逆アセンブルは参照していません。

| 検証集合 | 結果 |
|---|---|
| Signed_Probe 70入力 | 比較対象58入力は2回とも同じ対象レジスタ状態。12入力はMA4～7の波形エラーで比較対象ログなし |
| 比較可能58入力 | 0.33.2は42一致、0.33.3は48一致・10不一致。未一致はMP3/7、MA3のランダム波形 |
| 通常MA 21入力 | 544クロック×21入力＝11,424点のTL状態が全て一致 |
| 既存LFO_Comparison | 76入力中31一致・45不一致を維持。未一致はランダム波形。4入力は比較対象ログなし |
| 負の三角波を使う楽曲の対象区間 | 入力CRC32 AAE6F196、3キャリア×192クロック＝576点のTL状態が全て一致 |
| 旧Random_Probe | 17入力とも音程変化ゼロ。2回の記録は一致するが、乱数値を復元する測定としては使えない |

Signed_Probeはテンポ200・4 MHzの57,344 OPMクロック間隔で544回、同時刻の書き込みを全て適用後の状態を比較します。MPはKC/KF、MAはOP1のTLです。初期化と終了後の後処理は比較対象外です。バイナリ全体・書き込み順・全てのレジスタ・音声波形の完全一致を意味しません。

結果は `LFO_SIGNED_0.33.3.csv`。再現コマンド:

```text
python tools/compare_signed_lfo_logs.py OWN_LOG_FOLDER REFERENCE_1 REFERENCE_2 result.csv
```

Python 3標準ライブラリのみで実行します。同じディレクトリーのcompare_lfo_logs.pyも必要です。参照ログは再配布していません。

## ランダムLFOの追加検証

旧入力のMP7・生の深さ1では音程変化が出ませんでした。一方MP3・生の深さ93では変化があり、深さの演算のビット幅・符号と乱数生成を分離する必要があります。ゼロ出力だけで内部演算式や乱数生成器を断定していません。

`samples/LFO_Random_Depth_Probe` に68入力を同梱しています。34入力はMP3の深さ93/95と17段階のデチューン、残り34入力はMP3/MA3の正負と128/256付近の深さです。既存ログで変化が確認された93を主条件とし、95は量子化境界の補助条件に使います。原始MDXへ直接値を格納する独自データで、外部コンパイラは不要です。

比較対象ツールでこの新フォルダーだけを1ループ・フェードなしで2回記録し、別フォルダーに保存します。既存フォルダーの再取得は不要です。生成スクリプトは `tools/generate_random_depth_probes.py`、条件表と日英の取得手順は検証入力フォルダーに含まれます。

## 互換性と記録済みログ

既存設定を保持します。MRL/MRZは記録された値を再生するため、修正を反映するには元のMDXから再出力してください。MA4～7は既存の拡張として維持していますが、比較対象が受け付けないため互換性は未検証です。固定小数点の極端な値やオーバーフローを含む全条件の互換性を保証するものではありません。
