# IndependentMDX 0.33.1 architecture

The MDX parser and sequencer are in formats.cpp/player.cpp; vgm.cpp parses and schedules VGM register events. opm_backend.h dynamically loads the C ABI on Windows. Audio and per-channel visualization use the same DLL; external FM output uses a DLL-generated estimate for visualization. win_audio.h handles waveOut delivery.

VoiceState owns the original and edited MDX definitions. beginVoiceSession captures every defined instrument. A revision counter publishes edits to the audio thread, which updates matching tracks at block boundaries without resetting envelopes or timeline. New voice commands and seek reconstruction consult the edited definitions. MidiSynth also updates held audition voices. The GUI owns parameter controls and validates MML before publication. Selecting another file or starting a new playback captures a new baseline; seek and output continuation do not.

The voice editor layout and controls derive from NOTE-MDX-Workbench. All 47 editable parameters use the same MML conversion and bounds validation. Invalid partial text is retained in the focused field but never committed to synthesis.

RichEdit renders MML with per-parameter colors while preserving selection and scroll position. List-view custom drawing marks definitions that differ from the session baseline. Voice-window minimum height derives from nine text rows plus its layout and scrollbar margins. Visibility and normal placement share the existing two-second INI save path. Hiding the window does not destroy the editor or its edits.

vgz_export.h implements the headless batch entry point before GUI instance routing or INI access. It records timestamped YM2151 writes, renders PCM-only audio to signed 12-bit direct PWM, and merges both at 44.1 kHz VGM timestamps. A bounded-memory fixed-Huffman gzip writer compresses a temporary VGM. The final VGZ is published with no replacement of an existing path. Conversion uses the same MDX sequencer and PDX lookup as playback.

Offline export uses skipFmSynthesis to suppress only the synthesis backend, preserving the standard register sequence (external-device register routing is not used). skipPcmSynthesis skips sample-bank work for --no-pcm while interpreting all tracks. GD3 metadata is appended after the end command; the header points to its UTF-16LE field block.

Register logging uses the same batch traversal and atomic publication policy as VGZ export. Its 62,500 Hz sequencing steps map directly to 4 MHz time units by multiplication by 64. Records are captured before output-backend adaptations. OPM synthesis is omitted; PCM operations are recorded without decoding audio. PDX content is optionally embedded. MRZ wraps the stream in a single-member ZIP64 container. REGISTER_LOG_FORMAT.md defines the public interchange contract.

archive.cpp indexes ZIP32/ZIP64 directories and creates empty file placeholders. It extracts only requested members using a 32 KiB DEFLATE history and a 64 KiB output buffer. Title reads use a bounded prefix and do not cache complete MRL members. Selected MRL files use a 64 KiB event buffer; VgmSong retains a shared header/path descriptor rather than an event vector. The byte-array constructor remains available for small fixtures. Seek rebuilds FM and PCM state by replaying from the beginning. PCM sample decoding and the sound backend consume additional memory independent of ZIP size. ZIP data is never executed or loaded as a DLL.
