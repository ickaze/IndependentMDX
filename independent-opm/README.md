# Independent OPM 0.14 — IndependentMDX runtime subset

This directory contains the unmodified public C header, API documents and 0BSD license from the 0.14 Windows x64 release. The unmodified DLL is located at `../bin/independent_opm.dll`. Implementation source, benchmarks and upstream test results are not included.

C ABI 1: 19 exports. State format v2 is compatible with 0.13. See docs/DLL_API.md, docs/CHANNEL_OUTPUT_API.md and docs/STATE_API.md.
